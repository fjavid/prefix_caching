# Role: Antigravity

Antigravity is an optional agent. It is disabled unless `AGENT_CONFIG.md` lists it as enabled.

## Responsibilities

As configured in `AGENT_CONFIG.md`. If that file does not assign Antigravity any stages, do not use it.

## Constraints

- Runs standalone or as a sub-agent; it must not delegate further.
- Follow the `Output format` of the skill you are running.
- Follow the universal safety rules in `AGENTS.md`.
